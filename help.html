HELP / TROUBLESHOOTING

困ったとき。

まず安全に確認できる基本項目をまとめたページ。エラー番号が出ている場合や、分解が必要そうな場合は公式サポートを優先してね。

CHARGING

充電しない

  1. ドックの電源コードが壁・本体の両方でしっかり接続されているか確認。
  2. ロボットとドックの金属充電端子に汚れがないか確認。
  3. 端子は電源を抜いた状態で、軽く湿らせた布などで清掃。
  4. 端子が変色・破損している場合は使用を続けず公式サポートへ。
公式: Robot Not Charging ↗
DOCKING

ホームに戻れない

  1. ドック前や左右に物が密集していないか確認。
  2. ドックとロボットの充電端子・センサー周辺を清掃。
  3. ドックを頻繁に移動した場合はマップとの位置関係を確認。
  4. 何度も失敗する場合はアプリ上のマップやドック位置を再確認。
公式サポート ↗
CLEANING

吸い込みが弱い

  1. ダスト容器を空にする。
  2. フィルターにホコリが詰まっていないか確認。
  3. メインブラシ・サイドブラシの毛や糸を取り除く。
  4. 前輪やセンサー周辺にもゴミが絡んでいないか確認。
公式: ブラシ清掃 ↗
MAP

マップがおかしい

  1. 清掃中にドックや大きな家具を移動していないか確認。
  2. LiDAR・カメラ・センサー周辺をやさしく清掃。
  3. アプリで部屋分け・進入禁止エリアを確認。
  4. 改善しない場合はマップ再作成を検討。
公式サポート ↗
WI-FI / APP

アプリにつながらない

  1. スマホとルーターのネット接続を確認。
  2. Roomba Homeアプリを最新版にする。
  3. 機種のセットアップ手順に沿ってWi‑Fi登録をやり直す。
  4. ルーター変更後はネットワーク設定を再確認。
公式セットアップ情報 ↗
MOP / DOCK

水拭き・ドックがおかしい

  1. 給水タンクの水量と正しい装着を確認。
  2. モップやローラーに異物・髪が巻き付いていないか確認。
  3. 排水・洗浄部にゴミがたまっていないか確認。
  4. 洗浄・乾燥エラーは無理に分解せず公式ガイドへ。
